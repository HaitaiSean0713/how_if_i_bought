# 持倉文字與表格匯入

在「現有持倉」按 **匯入文字／表格**。貼上內容或選取檔案，按「解析內容」，校對欄位後按「預覽持倉變更」，最後確認套用。

支援 `.txt`、`.csv`、`.tsv`、`.md`、`.xlsx`，可選 Excel 工作表；舊版 `.xls` 請先另存 `.xlsx`。每次最多 300 筆、2 MB。文字檔可選 UTF-8 或 Big5。

## 文字範例

```text
2024/06/03 買進 2330 1000 股，每股 600 元
把 0050 調整為 2000 股，均價 150 元
2026/09/21 賣出 2330 500 股，每股 700 元
```

每行或每個分號一筆。`1 張` 代表 `1000 股`。未提供日期時使用畫面上的預設日期；沒有明確操作時使用畫面上的預設操作。規則式解析支援上述明確敘述，不是通用 AI；否定句、條件句、無法辨識的股票與缺少的欄位需自行校對。股票名稱只在能對應到已有持倉名稱時使用；建議直接寫代號。

## 表格範例

```csv
股票代號,股數,價格,日期,操作
2330,1000,600,2024-06-03,設定
0050,2000,150,2024-06-03,買進
```

有標題時可調整欄位順序，也支援常見的同義欄名，例如證券代號、成交股數、成本均價、交易日期、買賣。英文可用 `symbol,shares,price,date,action`。沒有標題時，依股票代號、股數、每股價格、日期、操作的順序排列。Excel 的股票代號請設為文字，保留 0050 等代號的前導零。日期支援西元與民國日期。

## 操作含義

- **設定總持股**：替換該股票所有持倉批次，使用指定股數、成本均價與日期；未列出的股票不受影響。
- **買進**：新增一筆持倉。
- **賣出**：依買進日期由早到晚扣除，建立平倉紀錄，禁止超賣或賣出當時尚未買進的部位。
- **刪除持股**：移除該股票現有持倉批次，不新增平倉損益。

既有平倉紀錄會保留。預覽顯示每筆操作前後的股數與持倉成本。確認後一次提交整批，失敗不會只儲存其中幾筆；預覽後若其他裝置修改持倉，必須重新預覽。重複套用買進／賣出會再次增減股數，請確認原始內容。

缺少價格時可手動填寫，或按「補齊缺少價格」，使用既有免費股價查詢接口。取得的是該日期或之前最近交易日的收盤價，不一定等於實際交易價格。查詢可以停止。

## 費用與資料

文字與檔案在瀏覽器本地解析，不需 AI API 金鑰、付費模型或新增後端服務。訪客模式寫入本地；登入模式沿用既有 Firebase 儲存。匯入功能不新增付費服務，但既有託管與資料庫的免費額度仍由其供應商管理。

Excel 解析使用 [read-excel-file](https://github.com/catamphetamine/read-excel-file)，MIT 授權；套件只在選取 Excel 時載入。文字解析、預覽及批次修改由本專案實作。
